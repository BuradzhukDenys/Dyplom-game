# Knight survivor

## Опис:
### Knight Survivor — це 2D гра в жанрі roguelite / arena survival. Ви граєте за лицаря, який має пережити хвилі ворогів, використовуючи магічні здібності, купуючи нову зброю та покращуючи свої характеристики.
## Можливості:
-  Динамічна система характеристик: Плоскі бонуси та відсотки.
-  Магазин та інвентар: Можливість купувати пасивні предмети та зброю.
-  Магінчні навички: Різні скіли, зі своїми характеристиками та поведінкою.
## Завантаження: [Release](https://github.com/BuradzhukDenys/Dyplom-game/releases/tag/Release)
## Керування:
-  Переміщення - `W` `A` `S` `D`
-  Атака - `LMB` (ЛКМ), `SPACE`
-  Зілля лікування - `F`
-  Зілля мани - `Q`
-  Інвентар - `X`
-  Характеристики - `Z`
-  Пауза - `ESC`
